Four Point Agenda

Keep the page clean enough to trust, strange enough to remember, and interactive enough that it feels alive without becoming carnival sludge. The cannibal angle is metaphor: art consuming memory, process eating doubt, signal feeding on old noise.

Frame

Start with one image-like emotional center. A domestic scene. Grass. Sunlight. A person holding a child. Ordinary enough to hurt.

Restrain

Let the first screen breathe. Sparse text. No forced lore dump. No cartoon gore. The best horror is usually just attention with bad intentions.

Corrupt

Add glitch, scanlines, chromatic ghosts, and hover effects as slow contamination. The page should feel reviewed by something nonhuman.

Merge Later

Keep this page self-contained until it earns its place. No dependencies. No sprawling asset mess. One clean branch before the wider system eats it.

Assessment Coach Note

Strong concept. The emotional reference photo gives it ballast. The cannibal language works if it stays symbolic: consumption, inheritance, revision.

Risk

Do not over-explain it. If the page gets too literal, it becomes Halloween plastic. Keep it tender first, unsettling second.

Signal Read

“The page should not announce danger. It should remember something until remembering becomes dangerous.”
